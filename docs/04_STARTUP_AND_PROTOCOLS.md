# Startup And Protocol Surface

## Application Startup

`RobloxApplication.onCreate` orchestrates:

1. StrictMode, localization, WorkManager, feature flags, and SDK setup.
2. `JNIActivityLifecycleCallbacks` is registered.
3. `JNIAAssetManagerSetup.initNative` and `LocalStorageManager.init...` expose
   Android asset/local-storage services to the engine.
4. `JNIBaseUrlProtocol.init` and `JNIWebLoginProtocol.init` register URL
   handlers.
5. `JNIAppLifecycleNativeAdapter` bridges process lifecycle events.

`ActivityNativeMain` owns the game `SurfaceView`, input/keyboard, app
lifecycle, screenshots, purchases, web views, notifications, device display,
media picker, WebRTC module download, and engine event delivery. The native
entry points are declared in `NativeGLInterface.java` and
`NativeSettingsInterface.java`.

## Flag And Configuration Path

`startup.C3084a` (`AndroidAppSettings`) coordinates remote app settings:

- Version A: remote JSON stored in `AndroidAppSettingsCache`.
- Version B: zstd-compressed flag cache with SHA/version metadata and
  burn-on-read semantics (`startup.FlagCacheUtils`).
- Local flags, OTA patch config, developer app settings, and device
  parameters are merged.
- `NativeGLInterface.readLocalFlags()` returns `ClientLocalFlags`.

Roblox channel, base URL, Roblox version, cache/files/external directories,
device info, proxy, cookies, user ID, and HTTP headers are set through
`NativeSettingsInterface`.

## Generated Protocol Bridge

`com.roblox.protocols.*.generated` is generated by Djinni/Snapchat-style code
generation. It contains Java interfaces, `CppProxy` native-object wrappers, and
callback registries. Mapped surfaces include:

- app age signals
- bug reporter
- connectivity v2
- design foundations
- device display
- example v2 handler
- external identity
- local storage (current user, secure values, per-user values)
- media picker
- pin shortcut
- system dialogs
- telemetry bindings

The exact Java-to-native pairs are in `analysis/maps/jni_bridge_arm64.csv`.
`analysis/maps/dex/roblox_protocol_classes.csv` inventories 103 Roblox protocol
classes carrying 138 native methods.

## Networking And Configuration

Native strings reference `roblox.com`, `ro.blox.com`, `rbxcdn.com`, API and
WebSocket/RTMP/RTC endpoints. Java-side OkHttp/Retrofit is present for
Persona, AppsFlyer, Firebase, billing, and Roblox web views. The manifest uses
system trust anchors only (`network_security_config.xml`), with cleartext not
globally enabled.

`analysis/maps/network_urls.csv`, `network_hosts.csv`, and
`network_owner_map.csv` classify all 100 unique hosts: 26 Roblox-owned hosts,
13 Google, 9 Persona, 2 telemetry/Backtrace, 5 standards, 4 local/test, and
the remainder as third-party or templated.
